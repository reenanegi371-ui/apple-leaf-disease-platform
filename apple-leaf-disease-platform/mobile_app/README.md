# LeafHealth AI - Mobile App

## Apple Leaf Disease Detection App

A Flutter-based mobile application for detecting diseases in apple leaves using AI.

## Features

- 📸 **Camera Capture**: Take photos of leaves directly
- 🖼️ **Gallery Import**: Select images from gallery
- ⚡ **Instant Detection**: AI-powered disease identification
- 📊 **Confidence Scores**: Detailed probability breakdown
- 💊 **Treatment Info**: Organic and chemical treatment recommendations
- 📋 **History Tracking**: Save and view past detections
- 🌙 **Dark Mode**: Theme support
- 📤 **Share Results**: Export and share detection reports

## Screens

1. **Splash Screen** - App loading animation
2. **Home Screen** - Main dashboard with recent detections
3. **Camera Screen** - Take leaf photos
4. **Gallery Screen** - Select images
5. **Results Screen** - Display detection results
6. **Disease Info Screen** - Detailed disease information
7. **History Screen** - Past detections
8. **Settings Screen** - App preferences
